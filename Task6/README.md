## Метрики для оценки эффективности классификации
### Метрики качества классификации 
- Точность (Precision): Доля правильно размеченных данных
- Полнота (Recall): Доля конфиденциальных данных, которые движок смог обнаружить, от общего реального объема конфиденциальных данных.
- Доля неклассифицированных данных (Unclassified Data Rate).
Эти метрики оценивают, насколько точно движок распознает конфиденциальную информацию.

### Метрики производительности
- Задержка обработки
- Влияние на загрузку данных
- Утилизация ресурсов
- Пропускная способность

### Метрики безопасности
- Количество конфиденциальных полей, ошибочно попавших в открытые слои DWH в обход маскирования
- Доля деперсонализированных данных

Анализируя данные метрики можно сделать вывод о качестве работы движка и о необходимости доработок, а так же об типах этих доработок.
