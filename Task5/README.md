# Задание 5. Разработка cutover-плана

Для данной миграции необходимо будет использовать комбинацию из всех трех вариантов миграции. 
На этапе подготовки и анализа необходимо использовать High-level design для автоматизации ручных процессов (создание архитектуры с нуля для ядря системы).
При разработке и внедрении сервисов будет использоваться mix Parallel run + Branch by abstraction.


В результате мы сможем применить совокупность глубокого анализа и бесшовного перехода на новое ПО с плавной перестройкой процессов и обучением.
